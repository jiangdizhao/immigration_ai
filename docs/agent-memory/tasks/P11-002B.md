## Accepted visual direction

The public site should feel like a premium Australian immigration/study professional-services platform.

Use these V4 principles:

- editorial/public mode with generous whitespace;
- strong but controlled headline hierarchy;
- tonal surfaces rather than excessive borders;
- controlled asymmetry;
- functional rather than cliché legal iconography;
- navy as institutional/platform authority;
- purple for AI;
- amber/gold for human lawyer/premium human service;
- green for verified/completed state;
- red only for genuine risk/urgency;
- neutral gray for metadata/inactive surfaces.

The existing P11-002A screenshots are the functional baseline, not a failure that needs redesign from scratch.

## Responsive requirements

Explicitly review behavior at approximately:

- 390px mobile;
- 768px tablet;
- 1280px desktop;
- 1536px+ wide desktop.

Requirements:

- no horizontal overflow;
- no clipped Chinese/English headings;
- language switch/header/account controls remain usable;
- hero CTAs remain reachable;
- cards stack logically;
- text line lengths remain readable;
- English long headings do not break the layout;
- no desktop-only content carries essential meaning that disappears on mobile.

The P11-001 shared header must remain functional.

## Motion and interaction

Restrained polish is allowed:

- subtle hover elevation;
- short opacity/transform transitions;
- restrained section/card emphasis.

Do not:

- add heavy scroll animation frameworks;
- add autoplay visual noise;
- use animation that hides content;
- compromise `prefers-reduced-motion`;
- make visual effects a dependency for understanding the page.

## Accessibility

Preserve or improve:

- semantic headings;
- focus visibility;
- button/link semantics;
- contrast;
- keyboard access;
- responsive text sizing.

Do not replace real DOM headings/buttons with decorative pseudo-content.
