## Gate A — Operator-reviewed first real-source acquisition (separate explicit owner authorization)
Scope exactly **one named URL / hostname / institution or CRICOS/Study Australia page**, enumerated allowed paths and redirects, source authority role, intended fields, provider scope, access terms/robots requirements, and a reviewed legal/operational policy for automated access. No undocumented bulk API assumptions. Before any traffic, implement/review a real hardened transport that actually pins resolved public IP(s) at the TLS connection boundary; enforce hostname certificate verification, connection/timing/size/redirect/charset/decompression and cancel semantics under adversarial tests. DNS rebinding, IPv4-mapped IPv6, redirects to private addresses, proxy bypass and unsafe ports must fail closed. Use an isolated disposable pilot, no production database or customer data. Preserve hash, full provenance, capture failures, uncertainty and operator adjudication; do **not** auto-promote claims to VERIFIED. Stop upon an access-policy or provenance violation. The pilot requires a distinct implementation, explicit scope approval, host test, independent review and audit record.
